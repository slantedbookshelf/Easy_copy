# 随记板（Easy-copy）

一款本地运行的 Windows 桌面悬浮文本暂存工具。核心工作流：**复制 → 查看 → 选取 → 再次复制**。

## 使用

运行 `dist/Easy-copy.exe`。软件启动后默认隐藏，仅驻留系统托盘；复制文本时窗口自动弹出，之后**保持常驻**，直到你手动关闭。

- 平时窗口隐藏，不占用桌面；在任意应用中复制纯文本后，窗口自动弹出并展示记录，保持你上次摆放的位置。
- 窗口默认不会自动消失；点"×"、"Esc"键或托盘图标即可隐藏。若希望"几秒无操作自动关闭"，可在设置中勾选"自动关闭"并调整秒数。
- 点击系统托盘右下角的"随记板"图标，可随时打开或隐藏窗口；右键图标菜单可暂停收集或退出。
- 记录按先后顺序从上到下排列，长文本默认折叠为约 4 行；点击"展开全文"查看，点击"收起"恢复。
- 拖选文本中的部分内容，按 `Ctrl+C`，只复制所选内容。
- 点击右下角"复制"，复制未经截断的完整原文；复制非置顶记录会把该条移到最上方；右键记录可选择复制、展开或删除。
- 拖动标题栏移动窗口，拖动右下角手柄调整大小，位置和大小即时保存。
- 标题栏"置顶"切换置顶状态，切换不会丢失窗口位置；"—"和"×"都只隐藏面板，不清空记录。
- 底部"设置"打开置顶显示的设置窗口，可调整保留条数、自动关闭、主题和开机启动。

记录只保存在本机 `%LOCALAPPDATA%\Easy-copy\records-v1.json`，窗口和设置保存在当前用户的应用配置中。默认保留最近 20 条，重复文本移到顶部，空白文本不记录。软件不上传剪贴板内容，不需要账号或网络。主动清空会永久删除本地记录。

## 从源码运行

需要 64 位 Windows 和 Python 3.11+。

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python -m easy_copy
```

## 打包

在项目目录执行：

```bash
.venv\Scripts\python -m PyInstaller --noconfirm --clean easy-copy.spec
```

生成单文件、无控制台窗口的 `dist/Easy-copy.exe`。可将该文件复制到其他 64 位 Windows 电脑运行；首次发布版本未做代码签名，如 SmartScreen 提示，请核验文件来源。

## 范围与已知限制

- 仅处理纯文本，不包含搜索、标签、图片、云同步或 AI 功能。
- 剪贴板被其他程序短时占用时，本次变化可能无法读取，后续剪贴板变化会重试。
- 开机启动仅对当前 Windows 用户生效。
- 窗口焦点、系统缩放和真实跨应用复制需要以实际桌面环境为准，自动化测试不宣称覆盖所有这些系统行为。
